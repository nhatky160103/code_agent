Basic Usage:
─────────────────────────────────────────
  from utils.llm_client import SmartLLMClient, LLMProvider
  from utils.rate_limiter import Priority
  
  # Initialize
  llm = SmartLLMClient(
      provider=LLMProvider.GEMINI,
      max_requests_per_minute=15
  )
  
  # Generate
  response = llm.generate(
      prompt="Create a function...",
      priority=Priority.HIGH,
      context="Core logic"
  )

Batch Generation:
─────────────────────────────────────────
  responses = llm.batch_generate([
      {
          'prompt': 'Create index.html',
          'priority': Priority.CRITICAL,
          'context': 'Main entry'
      },
      {
          'prompt': 'Create styles.css',
          'priority': Priority.HIGH,
          'context': 'Styling'
      }
  ])

Vấn đề: Vẫn bị rate limit
─────────────────────────────────────────
  Giải pháp:
    1. Giảm max_requests_per_minute xuống 10
    2. Tăng base_delay_seconds lên 10.0
    3. Sử dụng Priority.LOW cho non-critical files

Vấn đề: Circuit breaker mở
─────────────────────────────────────────
  Giải pháp:
    - Tự động recovery sau 3 phút
    - Hoặc đợi và restart
    - Check API quota status

Vấn đề: Context quá dài
─────────────────────────────────────────
  Giải pháp:
    1. Chuyển sang ContextStrategy.SLIDING_WINDOW
    2. Giảm max_context_tokens xuống 20000
    3. Enable caching để giảm requests

Vấn đề: Import errors
─────────────────────────────────────────
  Giải pháp:
    pip install -r requirements_intelligent.txt
    
    Hoặc:
    pip install google-generativeai structlog python-dotenv

🎓 BEST PRACTICES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Set priorities correctly:
   CRITICAL → index.html, main entry points
   HIGH     → core logic, components
   MEDIUM   → utilities, helpers
   LOW      → docs, examples

2. Choose right context strategy:
   HIERARCHICAL     → Best for most cases (recommended)
   SLIDING_WINDOW   → For very long tasks
   FULL_CONTEXT     → For simple tasks

3. Monitor and adjust:
   - Check success_rate regularly
   - Adjust parameters based on metrics
   - Start conservative, optimize later

4. Enable caching:
   - Saves API calls
   - Improves response time
   - Enable with enable_caching=True
